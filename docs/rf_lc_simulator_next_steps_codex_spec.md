## Feature 1 — Add S21 Phase Plot

### Purpose

The user needs to see how much phase rotation the LC structure creates across frequency.

This is essential because the structure is not only a filter; it is being studied as an artificial transmission medium / slow-wave structure.

### Requirements

Add a new plot:

```text
S21 Phase (degrees)
```

Use unwrapped phase.

### Calculation

For every frequency point:

```csharp
phaseRad[i] = Math.Atan2(S21.Imaginary, S21.Real);
```

Then unwrap using accumulated offset:

```csharp
double offset = 0;
unwrapped[0] = phase[0];

for (int i = 1; i < phase.Length; i++)
{
    double delta = phase[i] - phase[i - 1];

    if (delta > Math.PI) offset -= 2 * Math.PI;
    if (delta < -Math.PI) offset += 2 * Math.PI;

    unwrapped[i] = phase[i] + offset;
}
```

Convert to degrees:

```csharp
phaseDeg[i] = unwrapped[i] * 180.0 / Math.PI;
```

## Feature 2 — Add Group Delay Plot

### Purpose

Group delay shows how strongly the LC structure delays the wave.

This is directly relevant to slow-wave / artificial media behavior.

### Formula

```text
tau_g = -d(phi) / d(omega)
```

where:

```text
phi = unwrapped S21 phase in radians
omega = 2*pi*f
```

### Numerical Calculation

For interior points use central difference:

```csharp
groupDelay[i] = -(phaseRadUnwrapped[i+1] - phaseRadUnwrapped[i-1]) /
                (omega[i+1] - omega[i-1]);
```

For endpoints use forward/backward difference:

```csharp
groupDelay[0] = -(phase[1] - phase[0]) / (omega[1] - omega[0]);
groupDelay[N-1] = -(phase[N-1] - phase[N-2]) / (omega[N-1] - omega[N-2]);
```

Convert to ns:

```csharp
groupDelayNs[i] = groupDelay[i] * 1e9;
```

### UI Metrics

Show:

- average group delay
- maximum group delay
- minimum group delay
- group delay ripple

## Feature 3 — Export Touchstone .s2p

### Purpose

Allow the simulated result to be opened in RF tools such as QUCS, ADS, scikit-rf, or other RF viewers.

### Button

Add:

```text
Export S2P
```

### Touchstone Format

Use Touchstone v1:

```text
# Hz S RI R 50
! Generated by RF LC Structure Simulator
frequency_Hz  S11_real  S11_imag  S21_real  S21_imag  S12_real  S12_imag  S22_real  S22_imag
```

### Full ABCD to S formulas

Let:

```text
den = A + B/Z0 + C*Z0 + D
```

Then:

```text
S11 = (A + B/Z0 - C*Z0 - D) / den
S21 = 2 / den
S12 = 2 * (A*D - B*C) / den
S22 = (-A + B/Z0 - C*Z0 + D) / den
```

For ideal reciprocal passive cascades:

```text
A*D - B*C ≈ 1
```

## Feature 6 — Optional Parasitic Models

### Purpose

The ideal solver is useful, but real NanoVNA results differ because real components and PCB have parasitics.

Add optional parasitic modeling.

### UI

Add checkbox:

```text
Enable parasitics
```

Add editable values:

```text
Inductor ESR Ohm
Inductor parallel Cp pF
Capacitor ESR Ohm
Capacitor ESL nH
Trace series L nH
Shunt pad C pF
```

Suggested defaults:

```text
Inductor ESR = 0.2 Ohm
Inductor Cp = 0.1 pF
Capacitor ESR = 0.05 Ohm
Capacitor ESL = 0.5 nH
Trace series L = 0.5 nH
Shunt pad C = 0.1 pF
```

### Parasitic Series Inductor Model

Ideal:

```text
Series L
```

Parasitic model:

```text
Series ESR + L, with optional parallel Cp across the inductor
```

Simplified impedance:

```csharp
Z_L_series = ESR + j*w*L
Z_Cp = 1 / (j*w*Cp)
Z_total = parallel(Z_L_series, Z_Cp)
```

Then use `Z_total` as series impedance ABCD:

```text
[ 1  Z_total ]
[ 0     1    ]
```

### Parasitic Shunt Capacitor Model

Ideal:

```text
Shunt C
```

Parasitic model:

```text
Series ESL + ESR + C to ground
```

Impedance:

```csharp
Z_C = ESR + j*w*ESL + 1/(j*w*C)
Y_total = 1 / Z_C
```

Then use `Y_total` as shunt admittance ABCD:

```text
[ 1  0 ]
[ Y  1 ]
```

## Feature 7 — Validation / Sanity Checks

### Purpose

Prevent mistakes such as entering pF values as `e-11` instead of `e-12`.

### Required Checks

When loading JSON, warn if:

#### Suspicious Shunt Capacitor

If capacitor value > 500 pF:

```text
Warning: capacitor value is larger than expected for this experiment. Did you mean pF with e-12?
```

#### Suspicious Inductor

If inductor > 1 µH:

```text
Warning: inductor value is larger than typical selected range.
```

#### Empty Structure

Warn if no sections.

#### Invalid Alternating Structure

Warn if structure does not follow:

```text
SeriesL - ShuntC - SeriesL - ShuntC - SeriesL
```

unless advanced arbitrary mode is enabled.

## Feature 9 — Phase Smoothness Penalty

### Purpose

Avoid structures where phase rotation comes from a narrow resonance spike.

### Calculation

Use unwrapped phase and group delay.

Compute group delay ripple:

```text
GD_ripple = max(GD) - min(GD)
```

Add penalty if ripple too large:

```text
if GD_ripple > MaxAllowedGDRipple:
    penalty += weight * (GD_ripple - MaxAllowedGDRipple)^2
```

Suggested default:

```text
MaxAllowedGDRipple = 10 ns
```

### Performance Note — Optimizer Speed

Random search currently underuses available CPU resources. A 9-element optimization can take around 2 minutes, and larger 13-element searches may become impractically slow.

Future work should add parallel optimizer execution:

- parallel random restarts across CPU cores
- one random generator per worker
- thread-safe candidate collection
- throttled UI progress updates
- proper cancellation token support
- optional UI setting for worker/thread count

This should be implemented after the simulator review/export workflow is stable, because it changes optimizer execution flow and UI progress behavior.
